# プライバシーポリシー・データ取り扱い方針

ISF文化祭（2026-09-07）Bluetooth混雑検知システムにおける、来場者のプライバシー保護と
データ取り扱いの方針を定める。

> **注意**: 本ドキュメントの法的整理は一般的な見解の整理であり、法律の専門家による
> 助言ではない。実装詳細（データ保持期間・突合の有無など）を確定した上で、
> 必要に応じて弁護士に確認すること。

---

## 1. 計測の目的

- 文化祭当日の各ブースの混雑状況（おおよその人数レベル）を来場者・運営に提供する
- 収集したRSSIログを、将来の位置推定システムの検証・改善に利用する

上記以外の目的（特定個人の行動追跡、マーケティング、第三者への提供など）には
一切利用しない。

## 2. 計測の仕組みと取得データ

- スマートフォン等が発信する Bluetooth（BLE）の**アドバタイジングパケットの存在を
  検知してカウントするのみ**。通信内容の傍受・復号・記録は行わない。
- 検知した MAC アドレスは**スキャン時点で直ちにソルト付き SHA-256 ハッシュ
  （16文字に切詰め）で擬似IDに変換**し、生の MAC アドレスはメモリ上でも保持せず、
  保存・送信は一切しない（`scanner/bluetooth_scanner.py` の `hash_mac`）。
- 保存・送信するデータは以下のみ:

| データ | 内容 | 保存先 |
|---|---|---|
| 擬似ID | ソルト付きハッシュ（生MACへの逆引き不可） | ローカルCSV / RTDB / Vercel API |
| RSSI | 電波強度 | ローカルCSV / RTDB |
| タイムスタンプ・ブースID | 検知時刻と設置場所 | ローカルCSV / RTDB / Vercel API |

- 氏名・連絡先・端末所有者を特定できる情報は取得しない。

## 3. 法的整理（要点）

- **個人情報保護法**: MAC アドレス単体は「個人情報」に該当しない可能性が高いが、
  移動履歴・時刻・ブース滞在と組み合わせて蓄積すると個人識別性が高まりうる。
  本システムはソルト付きハッシュによる即時匿名化・保持期間の限定・ソルトの
  イベント後破棄（§4）でこのリスクを下げる。
- **通信の秘密（電気通信事業法など）**: 本システムはアドバタイジングパケットの
  存在検知によるカウントのみで、通信内容を復号・傍受しないため、通信の秘密の
  直接侵害には当たりにくいと解される。
- **透明性の確保**: 総務省・個人情報保護委員会は、Wi-Fi/Bluetooth による人流計測
  について、厳密に「個人情報」に当たらない場合でも**会場内掲示等での周知を推奨**
  している。本プロジェクトでは §5 の掲示で対応する。

## 4. データ取り扱いルール

1. **生MACの非保持**: 生 MAC アドレスは保存・送信しない（スキャン時に即時ハッシュ化）。
2. **ソルトの管理と破棄**: `MAC_HASH_SALT` は Private リポジトリで管理し、配布
   パッケージ以外に共有しない。**位置推定の検証・分析が完了した時点でソルトを破棄**
   し、以後は理論上も擬似IDと端末の対応付けを不可能にする。次回イベントでは新規
   ソルトを生成し、**年度をまたいだ個人単位の追跡は行わない**。
3. **保持期間**: RSSI ログ（ローカルCSV・RTDB）は位置推定システムの検証目的に限り
   保持し、目的達成後すみやかに、**遅くとも 2027-03-31（年度末）までに削除**する。
4. **利用の限定**: 擬似ID を個人の照会・特定・追跡に用いない。混雑カウントと
   位置推定の統計的検証のみに利用する。
5. **第三者提供の禁止**: 収集データを第三者に提供しない。
6. **オプトアウト**: 計測を希望しない来場者は端末の Bluetooth をオフにすることで
   計測対象から外れられる（掲示に明記する）。

## 5. 透明性確保（会場掲示）

会場入口および Surface 設置ブースに以下の掲示を行う。

### 掲示文テンプレート

```
【混雑状況の計測について】

本会場では、混雑状況の把握のため、スマートフォン等が発信する
Bluetooth信号を検知して台数をカウントしています。

・検知した識別子はその場で匿名化（暗号学的ハッシュ化）され、
  個人を特定できる情報は取得・保存しません。
・通信内容の傍受は行いません。
・データは混雑表示と統計的な検証のみに利用し、第三者には提供しません。
・計測を希望されない場合は、端末のBluetoothをオフにしてください。

お問い合わせ: ISFプロジェクト（文化祭実行委員会）
```

## 6. Webアプリのプライバシーポリシー記載文案（Shoki向け）

閲覧用 PWA のプライバシーポリシーに以下の趣旨を記載する。

> 本サービスの混雑状況表示は、会場内に設置したセンサーがスマートフォン等の
> Bluetooth 信号を検知し、台数をカウントすることで実現しています。検知した
> 識別子は直ちに匿名化され、個人を特定できる情報は取得・保存しません。
> 収集したデータは混雑状況の表示および計測精度の検証のみに利用し、
> 第三者に提供することはありません。

## 7. 問い合わせ対応

来場者から計測について問い合わせがあった場合は、本ドキュメント §2・§4 の内容を
説明する。データ削除の要望があった場合は、擬似IDから個人を特定できないため
個別削除は技術的に不可能であることを説明し、希望があれば Bluetooth オフでの
オプトアウトを案内する。
